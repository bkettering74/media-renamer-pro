# Media Renamer Pro

Rename movies, TV shows, music, photos, audiobooks and ROMs from the info inside the files. Every new name is shown to you first, and Undo puts everything back.

Works on Mac, iPhone and iPad. $4.99, one time.

**[Get Media Renamer Pro on the App Store](https://apps.apple.com/us/app/id6761764615)**

## What this repo is

This is the source for the Media Renamer Pro website and help guides, published at https://bkettering74.github.io/media-renamer-pro/. The app's own source code is not in this repo.
