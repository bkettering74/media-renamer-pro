How to set up your folders and filenames so renaming just works

The folder a file sits in tells the app almost as much as the filename does. Here is the layout that gets the best results for every kind of media, plus the template tricks most people never find.

Buck Kettering · September 2026

Media Renamer Pro reads three things for every file: the filename, the metadata inside the file, and the names of the folders around it. When the filename is thin, the folders fill the gap. So a tidy folder layout is the single biggest thing you can do to get clean names on the first pass.

None of this is required. The app will try its best with whatever you give it, and you can edit any row in the preview before anything moves. This is just the layout that needs the fewest edits.

The one rule that covers everything

Name the top folder for the thing itself, with the year in brackets:

Crusade (1999)/
Dune Part Two (2024)/
Stephen King - Hearts in Atlantis (1999)/

That folder name is what the app falls back on when a file inside it does not say what it belongs to. It is also exactly what Plex, Jellyfin, Emby and Audiobookshelf want, so you are not doing extra work for one tool.

TV shows

TV/
  Babylon 5 (1993)/
    Season 01/
      Babylon 5 S01E01 Midnight on the Firing Line (1993).mp4
  • Show folder: show name and year, Babylon 5 (1993).
  • Season folders: Season 01 is the standard. The app also recognises Season 1, Series 2, Specials, and short forms like B5 S01.
  • Filename: the one thing a TV file must have is the episode code, S01E01. Everything else can be looked up.

Files that start with the episode code

A lot of rips and downloads come named like this, with no show name at all:

Crusade (1999)/
  S01E01_War_Zone.mp4
  S01E02_The_Long_Road.mp4

From version 1.3.7, the app reads the code at the start of the name and takes the show and year from the folder. So these come out as Crusade S01E01 War Zone (1999).mp4 with no changes on your side. If the files sit inside a season folder, it looks one level up for the show folder.

On an older version? Put the show name in front of one filename, like Crusade S01E01_War_Zone.mp4, and preview again. Or use the template trick below to add the show name to every file at once.

Movies

Movies/
  Dune Part Two (2024)/
    Dune Part Two (2024).mkv
  • One folder per movie, named Title (Year).
  • Release tags like 1080p.WEB-DL.x265 in the filename are fine. The app strips them from the title and reads the resolution from them.
  • Keeping two copies of the same movie? Add {resolution} or {edition} to the movie template so each gets its own name, for example {title} ({year}) - {resolution} gives Dune Part Two (2024) - 4K.mkv. From 1.3.7, resolution is read from the video itself when the filename does not say.

Music

Music/
  Taylor Swift - Midnights/
    03 - Taylor Swift - Anti-Hero.m4a
  • Music is named from the tags inside the file first, so good tags matter more than good filenames.
  • Name album folders Artist - Album. When a track is missing its album tag, the app takes the album from that folder.
  • Multi-disc albums: keep the disc number in the tags, not in a separate folder per disc, where you can.

Audiobooks

Audiobooks/
  Stephen King - Hearts in Atlantis (1999)/
    01 - Stephen King - Hearts in Atlantis (1999).mp3
    02 - Stephen King - Hearts in Atlantis (1999).mp3
  • One folder per book, named Author - Title (Year). This is the folder the app trusts for author, title and year when the chapter files are just 01, Chapter 12 or Track 07.
  • Leave the track numbers in the chapter filenames. They are how the order survives the rename.
  • Cover art: a single image in the book folder is renamed to cover, which Audiobookshelf, Plex and Emby all pick up.

Game ROMs

Games/
  SNES/
    Chrono Trigger (1995) (USA).sfc
  • Keep one folder per system. It keeps collections apart and matches how emulator frontends expect them.
  • Region, revision and disc tags like (USA), (Rev 1) and Disc 2 are kept as their own tokens, so different dumps of the same game never collapse into one name.
  • More on why ROM names matter in the ROM naming guide.

Photos

2024-08-15 iPhone 15 Pro Sarah beach sunset Paris.heic
  • Photos are named from what is inside them, the date taken, camera, place and what is in the picture, so the folder does not matter much.
  • The folder template {year}/{month} sorts them into dated folders if you use Folders mode.
  • HEIC, JPEG, PNG and RAW formats like DNG, CR3, ARW and NEF all work.

Template tricks most people miss

Every media type has a file template and a folder template in Settings. Tokens in curly braces are filled in per file. Anything you type that is not a token is added to every file exactly as you typed it. That makes the template the fastest way to fix a whole batch at once.

Add a show name to every file

If a batch of files is missing the show name and the folder does not have it either, type it straight into the TV template for that batch:

Crusade {seasonEpisode} {episodeTitle} (1999)

Every file gets Crusade and (1999), and the episode code and title still fill in per file. Put the template back when you are done, or save it as a preset.

Add a label to everything in a batch

{title} ({year}) - Kids
{show} {seasonEpisode} {episodeTitle} [Remastered]
{date_taken} Vacation {city}

Keep what was already there

{original} drops in the old filename. Use it when you want to add clean titles without throwing away release group or quality tags:

{title} ({year}) {original}

Tokens that come up empty just disappear

If a file has no year, ({year}) is dropped cleanly rather than leaving empty brackets behind, so one template works across a mixed batch.

Save it for next time

Use Save Preset on the main screen to keep a media type, templates and options together, then pick it from Saved Setups next time.

Common edge cases and what to do

Shows and movies with numbers in the title

Babylon 5, 9-1-1, 2012, Blade Runner 2049. Numbers in a title can look like a year or an episode. Put the real year in brackets on the folder and in the filename, 2012 (2009), and the title number stops being ambiguous.

Remakes and shows that share a name

Battlestar Galactica (1978) and Battlestar Galactica (2004) are different shows. The year on the folder is what tells the lookup which one you mean. If it still picks the wrong one, edit that row in the preview.

Specials and season zero

Name specials as season 00, S00E01, and keep them in a Specials or Season 00 folder. Every major media server expects that.

Anime and absolute numbering

Files numbered Episode 137 with no season need a decision about aired versus absolute order before any renamer can help. The naming guide walks through it.

Extras, samples and featurettes

In TV mode, files with no episode code are skipped rather than guessed at, so behind-the-scenes clips and samples are left alone. Move them into an Extras folder so your media server treats them right too.

Two files that would get the same name

The first keeps the clean name and the rest get _1, _2, shown in the preview before anything moves. If they are really different versions, use {resolution} or {edition} in the template instead so each gets a meaningful name.

Finder copy names like (1)

A Movie (2010) (1).mkv left over from a copy is treated as the same title. The (1) is not carried into the new name.

Colons, slashes and other characters

Titles like Band of Brothers: Legacy contain characters that break on some systems. The app swaps them for safe look-alikes so the name works on a Mac, on Windows and on a NAS.

Subtitles next to the video

Subtitle files only attach when they share the video's base name. Turn on subtitle carrying in Settings, under Exclusions, and .srt and similar files are renamed with their video, language tags kept. More on the subtitle page.

Photos taken in the same second

Burst shots and multiple cameras can share a timestamp. They get _1, _2 rather than overwriting each other. Add {camera_model} to the template to tell cameras apart.

Multi-disc games and cue files

Disc tags are kept, but .cue and .m3u files point at the old names inside them. Check those after renaming. The ROM guide covers it.

Changing only the capitalisation

Renaming the office.mkv to The Office.mkv is harder than it looks on some drives and shares. The app handles it in two steps so nothing is lost. The details are in batch rename safety.

General habits that save the most time

  • Preview first, always. Nothing moves until you press Rename, and you can edit any single row.
  • Start with one folder. Get one show or one album right, save the template, then do the rest.
  • Pick the right media type. TV files previewed as Movies will not find their episode codes.
  • Files or Folders mode. Files renames the files inside. Folders renames the folders themselves.
  • Include subfolders when your files sit inside season or disc folders.
  • Undo reverses the whole last batch if something is not what you wanted.

FAQ

My TV files show "No season/episode code" and get skipped. Why?

The filename needs an episode code like S01E01, 1x01 or Season 1 Episode 1. If it has one and still skips, check that TV Shows is selected, and on versions before 1.3.7, that the code is not the very first thing in the name. See files that start with the episode code.

Do I have to rename my folders first?

No. But a top folder named Title (Year) gives the app a reliable fallback, and your media server wants that anyway, so it is worth doing once.

How do I add the same word to every filename?

Type it into the template around the tokens. Anything outside curly braces is added to every file as written. See template tricks.

The show or movie matched the wrong title. What now?

Edit that row in the preview, or add the year to the folder name and preview again. The year is usually what separates a show from its remake. You can also switch the provider in Settings, for TV between TVmaze and TMDb.

Can I undo a rename?

Yes. Undo reverses the whole last batch as one unit.

Does it work on files on my NAS?

Yes. Point it at a mounted SMB share on the Mac, or at the share through the Files app on iPhone and iPad. More in renaming over SMB and NAS shares.
