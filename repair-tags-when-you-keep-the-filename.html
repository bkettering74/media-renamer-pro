What to do when the tags and the file name disagree

The name says one song, the tag says another. The app stops and asks, and now it can fix the tags too.

By Buck Kettering· October 30, 2026· Applies to version 2.0

In this guide
  1. The review popup
  2. Keep filename
  3. Version labels in titles
  4. Files with no tag at the start
  5. Undo

The review popup

If the tags inside a file clearly disagree with its name, Media Renamer Pro does not guess. It lists those files in a review popup and asks you which one to trust: the tags, or the filename.

Keep filename

Choosing Keep filename means the name is right. With the tag editor and the repair option on in Settings, General, Tags, the app also rewrites the tags so the file agrees with its name. Where a file type cannot be written, the popup says only the name will change.

Repair covers music (MP3 and M4A), audiobooks (MP3, M4A, M4B) and movies and TV in MP4 or MKV. Only the fields that disagree are written. A chapter name in an audiobook's title tag is never touched.

Good to know: Changing tags changes the file itself. Apps that watch files for changes (backup, sync, download or media-manager tools) may treat it as a new or changed file. Undo puts it back exactly.

Version labels in titles

Songs often carry labels such as Remastered, Live or Radio Edit. By default a label that is not in the file name is left alone in the tag. There is an extra option, off by default, that also takes version labels out of song titles in the tags when the name has none. It applies to MP3 files.

Files with no tag at the start

Some MP3s have their tags only at the end of the file. To write a proper tag, the audio has to move. The app does this only after copying the original for Undo, checking that the audio is identical afterwards, and swapping the file in one step. Old end-of-file tags are left as they are.

Undo

Every repair is journaled. Undo puts the file back exactly. If the app is closed in the middle of a write, it recovers the file the next time you open it.
