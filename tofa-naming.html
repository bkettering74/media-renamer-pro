tofa file naming: how to get your library to match

tofa reads your folders where they sit and never renames anything, so the names you already have decide whether a title matches. Here is what its own docs say it expects.

By Buck Kettering· November 1, 2026· 3 min read

In this guide

  2. TV shows
  3. Multi-episode files and specials
  4. Editions, 4K and 1080p
  5. Subtitles
  6. What tofa skips

  8. Checklist

tofa is a self-hosted media server that is currently in beta. It reads your folders in place and does not rename or move anything, so the names you already have decide whether a title matches. This guide follows tofa's own naming documentation as I read it on November 1, 2026. Because it is a beta, check docs.tofa.tv for the current rules.

Movies

Use one folder per movie, named with the title and year. Loose files in the library root also work. The year is optional, but it is what tells remakes apart, so include it.

Movies/
  Harbor Lights (1995)/
    Harbor Lights (1995).mkv

Quality tags such as 2160p or HDR are ignored for matching. A movie split across files stacks into one title when the parts are numbered cd1 and cd2, part1 and part2, or disc1 and disc2. Disc folders such as VIDEO_TS and BDMV are supported, and the folder that holds them supplies the title and year.

TV shows

Use a folder for the show, a folder for each season, and put the season and episode marker in the file name.

Shows/
  Northbound (2022)/
    Season 01/
      Northbound S01E01.mkv

Season folders can be Season 01, Season 1 or S01. S01E02 is the most reliable episode marker. tofa also recognizes 1x02, EP02, air dates for daily shows, and plain numbers for absolute-numbered shows. If two shows share a name, put the year in the show folder, like Night Watch (1990) and Night Watch (2014).

Episode order is set per show as Aired (the default), Absolute or DVD. Changing it does not affect watch progress.

Multi-episode files and specials

A file that holds two episodes takes a range in the name, such as S01E01-E02. Specials go in a Specials or Season 00 folder, or get S00E01 style numbers.

Editions, 4K and 1080p

Editions use a tag in curly braces, such as {edition-Colour} or {edition-Black and White}. On an episode file name the tag creates an edition picker inside one show. On a show folder it creates separate listings with separate watched state.

For 4K and 1080p copies, give both files the same title and year and let only the quality tag differ. Copies in the same library merge on their own. Across libraries you need to turn on Cross-library version merge under Admin, then Libraries.

Movies/
  Harbor Lights (1995)/
    Harbor Lights (1995) 2160p.mkv
    Harbor Lights (1995) 1080p.mkv

Subtitles

Embedded text and image-based tracks work. External SRT, ASS/SSA and VTT files should be named after the video, with an optional language code and flags, or placed in a Subs folder. Use two or three letter language codes. The flags forced, sdh and cc mark forced and hearing-impaired tracks.

Harbor Lights (1995).en.forced.srt
Harbor Lights (1995).is.sdh.srt
Subs/german.srt

What tofa skips

  • A show file with no recognizable episode marker. (A movie without a year still scans.)
  • Trailers, samples and extras: names like trailer.* or sample.*, and anything in folders named Extras or Trailers.
  • Any folder holding a .tofaignore or .nomedia file, along with everything beneath it.
  • Unfinished downloads.

When a title will not match

Titles tofa cannot identify show up under Admin, then Hygiene, on the Unknown titles tab. Its own docs say that renaming the file is often the real fix.

If tofa matched the wrong title instead, use Fix match on the movie or show page in the web interface, signed in as the admin on the main profile. That corrects the match without renaming files, so your names on disk stay as they are.

Checklist

  • One folder per movie, with the year
  • Show folder, season folder, and S01E01 in every episode file name
  • The year on the show folder when two shows share a name
  • Ranges like S01E01-E02 for two-in-one files, specials in Season 00
  • Same title and year on 4K and 1080p copies, only the quality tag different
  • Subtitles named after the video, with language and flag codes
  • Anything left over in the Unknown titles tab: rename the file first
