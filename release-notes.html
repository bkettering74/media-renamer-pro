Release notes

What changed in each version, in plain words.

Version 2.0: edit tags, fix matches

Edit tags

  • Open the tag icon on a row to see and edit the title, artist, album, show, year and cover art.
  • Preview exactly what will be written before anything is saved. Undo puts the file back exactly.
  • Clean tags wipes junk tags. Fill from filename and Fill from lookup add the missing ones. Blank fields only, and lookups fill confident matches only.
  • Works on MP3, MP4 and MKV files.
  • Find cover online shows the pictures, you pick one, and it embeds cover art inside the file's tags.

Changing tags changes the file itself. Apps that watch files for changes (backup, sync, download or media-manager tools) may treat it as a new or changed file. Undo puts it back exactly.

Fix match

  • Wrong movie, show, song or book? Pick the right one yourself. It remembers your choice.
  • The information panel opens from the tag icon on a row.

Confidence

  • The percentage on each row is now worked out from real evidence. Hover to see the reason.

Better names and speed

  • Keeps the year in your file name when a title is ambiguous.
  • TV episode titles use proper title case.
  • Real colons in tags, look-alike colons in file names.
  • Skips the hidden "._" files that Macs leave on network drives.
  • Faster on big music folders and repeat runs.
  • Watched folders: the eye button only loads the type you are on.

Version 1.4: the workflow update

  • New + and − buttons under your file list. Add more files or folders any time without starting over. − only takes a row off the list. Your files are never touched.
  • Watched Folders: save the folders you rename most and load them with the eye button. New only skips files you already renamed.
  • Experienced layout: hides the guidance, tightens the spacing and moves Preview, Rename and Undo to a bar at the bottom.
  • A new Settings with a sidebar. Changes save automatically.
  • The Show Sidebar button no longer shows up blank.

Thanks to the customer who mocked up these ideas.
